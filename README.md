# Качество вина
## Запуск

Проверено с Python 3.12.14. Используйте Python 3.12 и версии библиотек из `requirements.txt`.

Из папки `wine_app` выполните:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows активируйте окружение командой `.venv\Scripts\activate` вместо `source .venv/bin/activate`.

Откройте адрес, показанный Streamlit, обычно `http://localhost:8501`. После установки зависимостей приложение работает без загрузки данных из интернета. Файлы модели и данных должны находиться рядом с `app.py`; их пути строятся относительно расположения скрипта.

## Вкладки

- «Оценка одного вина»: ввод 12 признаков, вероятность хорошего вина и решение при выбранном пороге. Диапазоны числовых полей и медианы взяты из `test.csv`; цвет вина задаётся переключателем.
- «Модельные метрики»: матрица ошибок, precision, recall, F1, ROC- и PR-кривые с текущей рабочей точкой.
- «Пакетное предсказание»: загрузка CSV и скачивание результатов. `probability_good` — вероятность класса 1, `prediction` — решение 0 или 1 при текущем пороге.
- «Что выучила модель»: отсортированные коэффициенты после стандартизации признаков и наиболее выраженные положительные и отрицательные признаки.

Порог в боковой панели общий для всех вкладок. Повышение порога уменьшает подборку и полноту; снижение увеличивает охват и число ложных рекомендаций.

## Формат CSV

Нужна строка заголовков и следующие числовые столбцы, разделённые запятыми:

```text
fixed_acidity,volatile_acidity,citric_acid,residual_sugar,chlorides,free_sulfur_dioxide,total_sulfur_dioxide,density,pH,sulphates,alcohol,is_red
```

`is_red` принимает 1 для красного вина и 0 для белого. Столбец `target` для предсказания не нужен. Порядок признаков в загружаемом файле может отличаться: перед предсказанием приложение восстанавливает порядок модели. При отсутствующих столбцах, нечисловых данных, пропусках или неверном значении `is_red` выводится сообщение об ошибке.

Для проверки пакетного режима можно создать CSV из `test.csv`, удалив столбец `target`.

## Кэширование

`load_model` использует `st.cache_resource`: один загруженный объект модели повторно используется на сервере между перезапусками скрипта и сеансами пользователей. Приложение вызывает у него только методы предсказания.

`load_test_data` и `test_proba` используют `st.cache_data`, предназначенный для таблиц и массивов. Он сохраняет вычисленный результат и возвращает отдельную копию данных вызывающему коду. Аргумент `_model` исключён из хеширования, а `X` участвует в ключе кэша.

При изменении порога вероятности на тестовой выборке берутся из кэша. Пересчитываются метки, метрики и положение рабочей точки; вероятности введённого пользователем вина и загруженного CSV вычисляются отдельно. Без декоратора вызов `joblib.load` заново читал бы модель с диска при каждом действии пользователя.

## Развёртывание в Streamlit Community Cloud

1. Загрузите содержимое архива в свой GitHub-репозиторий, сохранив папку `wine_app` со всеми шестью файлами.
2. Войдите в [Streamlit Community Cloud](https://share.streamlit.io/) и выберите `Create app`.
3. Укажите репозиторий, ветку и путь к основному файлу: `wine_app/app.py`.
4. В `Advanced settings` выберите Python 3.12 и запустите развёртывание. Зависимости установятся из `wine_app/requirements.txt`.
5. Проверьте открывшееся приложение и добавьте его фактическую ссылку в сдачу вместе с архивом.
